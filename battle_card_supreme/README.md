# Battle Card Supreme (Offline Prototype)

Flutter offline MVP for **Battle Card Supreme** / **Aetherium Rift**.

## Run

```bash
cd battle_card_supreme
flutter pub get
flutter run
```

## Test

```bash
flutter test
```

## What's included

- Design Prefer themed shell (home, vault, squad, card detail, battle, results)
- 12 seed cards across Common to Supreme with divided stat budgets
- Pure Dart combat engine + simple AI
- Unit tests for budgets and combat
